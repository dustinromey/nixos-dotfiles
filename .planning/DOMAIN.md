# Domain Knowledge: Romey NixOS

> This file contains rules that AI agents MUST reference when planning and executing work.
> It grows over time — start sparse, get richer with every project.
> Rules here override AI assumptions. When in doubt, check DOMAIN.md.

## System Model

- **What this is:** Multi-host NixOS configuration managed via Nix flakes
- **Host topology:**
  - **mischief** — Lenovo ThinkPad X270, Intel i5-6300U, Intel HD 520 GPU (test machine)
  - **intrepid** — Desktop, AMD CPU/GPU, 32GB RAM (daily driver)
  - **vigilant** — Microsoft Surface Laptop 4, AMD CPU/GPU, 16GB RAM
- **Configuration pattern:** Common base + per-host overrides

## NixOS Rules

- **LSP servers via Nix, not Mason** — All language servers are installed through home.nix, never through Neovim's Mason plugin
- **lib.mkDefault in common config** — Common configuration uses `lib.mkDefault` so host-specific files can override cleanly
- **Config symlinks** — Application configs live in `config/` and are symlinked to `~/.config/` by home-manager; do not place configs directly in home-manager Nix expressions unless necessary
- **Formatting** — All Nix files must pass `nixfmt-rfc-style`
- **Flake inputs** — New external flakes are added as inputs in `flake.nix` and threaded through to modules via `specialArgs` or home-manager `extraSpecialArgs`

## Hardware Rules

- **GPU split:** intrepid and vigilant use AMD GPU drivers; mischief uses Intel
- **Package variants:** When a package offers GPU-accelerated variants, use Vulkan for AMD hosts and CPU/default for mischief
- **Surface kernel:** vigilant uses the linux-surface kernel for hardware support (touchpad, etc.)

## Integration Contracts

| Data Type | System of Record | Notes |
|-----------|-----------------|-------|
| NixOS system config | `hosts/<hostname>/configuration.nix` | Imports common + hardware config |
| Home-manager config | `hosts/<hostname>/home.nix` | Imports common home.nix |
| App configs | `config/<app>/` | Symlinked to ~/.config/ by home-manager |
| Per-host config overrides | `config-overrides/<hostname>/` | Optional, overlays on top of shared config |
| Hardware config | `hosts/<hostname>/hardware-configuration.nix` | Generated by nixos-generate-config, not hand-edited |

## Explicit Constraints

- NEVER install language servers via Mason/Neovim — always use Nix packages in home.nix
- NEVER edit hardware-configuration.nix by hand — it is generated by `nixos-generate-config`
- NEVER put application configs inline in Nix expressions when they can be symlinked from `config/`
- NEVER skip `nixfmt-rfc-style` formatting on Nix files
