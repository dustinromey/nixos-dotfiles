Per user decision: pin to v0.6.4 tag, use nixpkgs.follows to prevent double evaluation. This follows the exact same two-line pattern used by sops-nix, claude-code, home-manager, and fresh.

4. Delete the `packages/waystt/` directory entirely: `rm -rf packages/waystt`

5. Format with `nixfmt-rfc-style flake.nix`

IMPORTANT: The overlay removal and packages/waystt deletion must happen in this task because Task 2 removes the waystt reference from systemPackages. Both changes are needed together to avoid undefined variable errors.
