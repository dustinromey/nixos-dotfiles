  <name>Task 1: Fix PATH workaround to use evaluated config</name>
  <files>hosts/common/home.nix</files>
  <action>
In hosts/common/home.nix, change the systemd PATH workaround from hardcoded package reference to evaluated config reference.

Change line 80:
```
"PATH=/run/current-system/sw/bin:${inputs.voxtype.packages.${pkgs.system}.default}/bin"
```
to:
```
"PATH=/run/current-system/sw/bin:${config.programs.voxtype.package}/bin"
```

This ensures that when a host overrides `programs.voxtype.package` to the Vulkan variant, the systemd service PATH points to the correct binary. Without this fix, Vulkan hosts would still have the CPU binary in their PATH.

Also wrap the `programs.voxtype.package` assignment with `lib.mkDefault` so host-specific overrides take precedence:
```nix
package = lib.mkDefault inputs.voxtype.packages.${pkgs.system}.default;
```
